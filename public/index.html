Aide-mémoire

    
Les instructions s'écrivent comme dans AlgoBox. Les boutons « Insérer » ajoutent chaque structure toute prête là où se trouve le curseur.

    

      
Déclarer une variable
x EST_DU_TYPE NOMBRE
nom EST_DU_TYPE CHAINE
L EST_DU_TYPE LISTE
Les déclarations se placent entre VARIABLES et DEBUT_ALGORITHME. CHAINE sert pour du texte.

      
Demander une valeur
LIRE x
Une case de saisie apparaît dans la sortie. Pour un décimal, le point et la virgule sont acceptés.

      
Donner une valeur
x PREND_LA_VALEUR 2*x + 1
Le calcul de droite est fait d'abord, puis le résultat est rangé dans x.

      
Afficher
AFFICHER "x vaut ", x
Chaque AFFICHER passe à la ligne. Les virgules mettent plusieurs éléments sur la même ligne.

      
Condition
SI (x > 0) ALORS
  DEBUT_SI
  AFFICHER "positif"
  FIN_SI
SINON
  DEBUT_SINON
  AFFICHER "négatif ou nul"
  FIN_SINON
Le bloc SINON est facultatif.

      
Boucle POUR
POUR i ALLANT_DE 1 A 10
  DEBUT_POUR
  AFFICHER i
  FIN_POUR
Le compteur i doit être déclaré comme NOMBRE. Il augmente de 1 à chaque tour.

      
Boucle TANT_QUE
TANT_QUE (x < 100) FAIRE
  DEBUT_TANT_QUE
  x PREND_LA_VALEUR x * 2
  FIN_TANT_QUE
La boucle s'arrête dès que la condition devient fausse. Au-delà d'un million de tours, l'algorithme est arrêté.

      
Comparer, combiner
x == 3    x != 3    x <= 3
(x > 0) ET (x < 10)
(n == 1) OU (n == 2)
== veut dire « égal », != veut dire « différent ». On peut aussi utiliser NON.

      
Calculer
sqrt(x)   pow(x,3)   abs(x)
floor(x)  round(x)   n % 2
random()  ALGOBOX_ALEA_ENT(1,6)
% donne le reste de la division. ALGOBOX_ALEA_ENT(a,b) donne un entier au hasard entre a et b. Math.PI vaut π.

      
Listes
L[1] PREND_LA_VALEUR 5
AFFICHER L[1]
Les éléments sont repérés par leur rang entre crochets, en général à partir de 1.

      
Fonction
FONCTIONS_UTILISEES
FONCTION carre(x)
VARIABLES_FONCTION
  // variables de la fonction
DEBUT_FONCTION
  RENVOYER x*x
FIN_FONCTION
VARIABLES
  …
DEBUT_ALGORITHME
  r PREND_LA_VALEUR carre(a)
  APPELER_FONCTION afficherTout(a)
Les fonctions s'écrivent avant VARIABLES. RENVOYER donne le résultat et quitte la fonction. Une fonction sans RENVOYER (qui ne fait qu'afficher) s'appelle avec APPELER_FONCTION. Les paramètres sont des copies : les modifier ne change pas les variables de l'algorithme principal. Une fonction peut utiliser directement une LISTE déclarée dans VARIABLES.

// ce texte est ignoré
Pratique pour expliquer son algorithme.
